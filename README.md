# Bookstore Database System

A database design project developed as part of a university course, focusing on organizing and managing bookstore information using relational database concepts and SQL.

## Project Overview
The project presents a fictional bookstore database system designed to organize information about books, customers, branches, categories, and orders.

It demonstrates how entities and their relationships can be represented through an Entity Relationship Diagram (ERD), converted into a relational schema, and implemented using SQL commands.

## Key Features
- Designed an Entity Relationship Diagram (ERD) to represent database entities and relationships.
- Developed a relational schema with primary and foreign key relationships.
- Defined database tables for books, customers, branches, categories, and orders.
- Used SQL Data Definition Language (DDL) commands to create database tables.
- Applied Data Manipulation Language (DML) commands to insert and manage sample data.
- Demonstrated six SQL queries for retrieving information from the database.

## Implementation
The project covers the following database design and implementation stages:

- **Entity Relationship Diagram (ERD):** Identifies the main entities, attributes, and relationships.
- **Relational Schema:** Defines the database structure and relationships between tables.
- **DDL Commands:** Creates the database tables.
- **DML Commands:** Demonstrates data insertion and manipulation.
- **SQL Queries:** Retrieves information from the database using SQL statements.
